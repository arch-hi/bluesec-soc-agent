# BlueSec SOC Agent

LLM-агент для расследования алертов SOC. Он получает срабатывание, изучает связанные события, процессы, файлы, сетевые соединения и учётные записи и решает, атака это или ложное срабатывание. К вердикту агент прикладывает отчёт для реагирования.

Проект сделан для соревнования [BlueSec SOC Agent Challenge](https://bluesec.team/) от Positive Technologies и сообщества False Positive, осень 2026. Агент занял 4 место на тренировочном этапе и 13 место из 76 в [финале](https://bluesec.team/leaderboard?board=accuracy).

## Как работает

Агент использует недорогую модель DeepSeek V4.1 Flash, а основную работу делает код вокруг неё. Модель решает, какой инструмент вызвать следующим, а код

- до первого хода модели ищет учётные записи и хосты из алерта, такие поиски чаще всего находили нужные сущности
- отклоняет вызовы с несуществующими или перепутанными идентификаторами, не тратя запрос к серверу
- следит за бюджетом вызовов для каждого типа алерта, бюджеты посчитаны по логам тренировки и уточняются во время прогона
- по наградам за вызовы отмечает, какие найденные сущности относятся к инциденту, и убирает из отчёта лишнее
- исправляет отчёт, если модель записала его в неверном формате

В финале организаторы скрыли все метрики, включая награды. Агент сам это определяет и переходит на правила, выведенные из тренировочных отчётов. Этот режим заранее проверялся на тренировочных задачах со скрытыми наградами.

## Результаты

На тренировке лучший прогон набрал 21.05 балла из 30. В финале агент прошёл все 40 задач за 77 минут без сбоев, набрал 22.67 балла и дал верный вердикт в 38 задачах. Больше всего баллов ушло на неполные отчёты, остальное на две ошибки вердикта и перерасход вызовов.

## Структура

- src/bluesec1_agent, код агента
- src/bluesec1_client, клиент сервера соревнования из стартового набора организаторов
- scripts, просмотр логов прогона и проверка перед запуском
- tests, тесты
